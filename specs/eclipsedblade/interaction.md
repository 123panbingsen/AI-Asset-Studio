## 全局交互原则

- 触控热区：主按钮 ≥88×88；列表项整行可点。
- 反馈层级：点击态（缩放 0.94）→ 结果反馈（Toast/弹窗）→ 异常提示。
- 替换技能、洗点、放弃技能、解除契约等破坏性操作必须二次确认。
- 动效 150–300ms；提供减少动效替代。
- 文案短中文；素材默认无字。
- **3 分钟回流原则**：上线 → 领离线 → 看报告 → 打一次试炼 → 关掉，必须 ≤3 次页面跳转；蓝图编辑等深度内容不得挡住日常闭环。
- **状态优先**：离线收益、蚀化、保护位、保底进度首屏可见。

## 页面：onboarding（开局）

- **目的**：三选一永久技能 + 60 点属性。
- **进入**：新档首次启动。
- **主流程**：三选一卡（Eclipsed Blade / 永夜之心 / 光蚀引擎）→ 确认 → 六维分配（单项 ≤24）→ 确认 → home。
- **控件**：3 张技能卡、六维 +/-、剩余点数、重置、确认。
- **状态**：`incomplete`（未分配完/超限禁用确认）、`default`。
- **退出**：不可返回；确认写档。

## 页面：home（主城/挂机）

- **目的**：回流第一屏；3 分钟内完成收菜-试炼闭环。
- **进入**：启动默认页；Tab 主城。
- **主流程**：蚀化警告条（若有）→ 离线报告（若有）→ 选安全/冒险 → 开始挂机 → 收益/蚀值/试炼 → 试炼或主线/竞技。
- **控件**：蚀化警告条（「有技能被蚀化 · 点击修复」）、离线报告入口、安全/冒险切换、开始/停止、日蚀倒计时、主线 CTA、任务入口、竞技入口、NPC 导师入口、角色/宠物状态卡。
- **状态**：`default`、`offline-capped`、`eclipse`（时段高亮）、`corroded`（警告条）、`battle`（挂机战斗演示）。
- **规则**：冒险模式二次确认（失败有代价）；离线超上限提示按上限结算；蚀化警告条优先级高于其他入口。

## 页面：offline-report（离线报告）

- **目的**：一次展示离线产出与试炼结果，一键领取。
- **进入**：home 有离线数据时弹出。
- **主流程**：时长/资源/技能/试炼胜败/蚀化/保底 → 领取 → home。
- **控件**：领取、展开详情、关闭（不领取保留）。
- **状态**：`default`、`offline-capped`、`corroded`（报告内高亮蚀化技能并可跳转修复）。

## 页面：trial（技能试炼）

- **目的**：Build 验证与技能获取。
- **进入**：挂机触发 / 主城试炼入口。
- **主流程**：确认阵容 → 战斗 → 胜利：三选一（替换/放弃）→ 失败：蚀化提示（保护位优先、保底进度）→ 返回挂机。
- **控件**：出战确认、三选一卡、替换/放弃、蚀化修复跳转、退出。
- **状态**：`default`、`incomplete`、`pity-ready`、`corroded`（失败后）。
- **规则**：前 3 次必成功或必出稀有；连续失败 3 次保底；蚀化不是删除；失败后若产生蚀化，回主城必须触发警告条。

## 页面：skills（技能）

- **目的**：管理永久/非永久技能、保护位、蚀化净化、洗点。
- **进入**：Tab 技能；试炼结算跳转。
- **主流程**：槽位 → 技能详情 → 升级/升星/保护/净化 → 洗点 → 蓝图入口。
- **控件**：槽位列表（1 永久 + N 非永久）、详情、保护位开关、净化（免费材料 + 加速道具）、洗点、蓝图入口。
- **状态**：`corroded`、`slot-full`、`protected`、`locked`。

## 页面：blueprint（蓝图，P0 个人版）

- **目的**：个人受限蓝图创作（不公开、不审核）。
- **进入**：Tab 蓝图；技能页入口。
- **主流程**：新建/选草稿 → 模板 → 触发 → 词条（+/- 层数）→ 冷却 → 标签 → 预算条 → 预览 → 保存草稿 → 选择「测试版」或「正式版」。
- **控件**：模板 chips、触发 chips、词条行、冷却步进、标签、预算条（超预算变红）、预览卡（DPS/蚀值/触发频率）、保存草稿、升级为正式版、草稿列表。
- **状态**：`default`、`incomplete`、`over-budget`（禁用正式保存）、`draft`、`testing`、`live`。
- **规则**：超预算禁止保存正式版；草稿随时可存；本页不做分享/审核（P1）。

## 页面：pet（宠物）

- **目的**：独狼成长线。
- **进入**：Tab 宠物。
- **主流程**：收留 → 选训练方向 → 离线训练 → 学技能 → 亲密度 → 功能型羁绊技 → 进化。
- **控件**：宠物列表、训练位、技能槽、亲密度条、羁绊技预览（离线收益/净化速度/掉落率）、进化、孤狼契约（二次确认）。
- **状态**：`default`、`training`、`locked`、`max`。

## 页面：story（主线）

- **目的**：串起系统解锁与区域推进。
- **进入**：主城 CTA。
- **主流程**：五幕地图 → 当前节点 → 完成目标 → 领奖 → 解锁下一区域。
- **控件**：幕/节点、目标列表、前往、奖励预览、剧情文本。
- **状态**：`locked`、`default`、`complete`。

## 页面：arena（镜像切磋，简化版）

- **目的**：异步验证 Build（战力镜像）。
- **进入**：主城入口。
- **主流程**：设置防守阵容 → 选对手 → 战斗 → 结算排名分 → 返回。
- **控件**：防守阵容、对手列表、免费次数、退出。
- **状态**：`default`、`daily-limit`、`locked`（禁用创作技能提示）。
- **规则**：创作技能不可上场；社交加成不生效；无赛季/段位（P1 再做）。

## 页面：battle（战斗/试炼/切磋）

- 控件：摇杆、普攻、技能 x3、退出、双方血条。
- 状态：`running`、`win`、`lose`。

## 页面：bag / shop / quest

- **bag**：技能/材料/道具；自动分解规则；背包上限提示。
- **shop**：资源、外观、槽位、测试次数；不出现预算/强度/审核权商品；标注「不增加战斗强度」。
- **quest**：日常/周常/主线；领取幂等。

## 跨页链路

```text
onboarding → home → 挂机 → trial → 三选一 → skills → home
home → offline-report → home
home → 蚀化警告条 → skills（净化）→ home
skills → blueprint → 保存草稿 → trial（测试）
pet → 训练 → 功能型羁绊 → home
home → arena → 结算 → home
story → 节点 → trial/挂机 → 解锁区域
home → quest → 领取 → home
```

## 与视觉稿的约束

- 首屏必露：蚀化警告条（有则最高优先级）、离线报告、挂机模式、日蚀时刻、主线 CTA。
- 禁遮挡：底部 Tab 与挂机主按钮不得被公告/弹窗遮挡。
- 主操作强调：开启挂机 > 试炼 > 商城；蓝图编辑不得抢占主城首屏。
- 状态色：蚀化=暗紫，保护=金，保底=红金，日蚀=高亮，超预算=红。
- 蓝图页：预算条与预览卡必须同屏可见，避免「编辑时看不到代价」。
