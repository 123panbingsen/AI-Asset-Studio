## 概述

- 项目 ID：`eclipsedblade`
- 产品目标：交付竖屏放置 RPG 的 **MVP 垂直切片**，验证「挂机 → 试炼 → 换技能 → 变强 → 再挂机」，包含宠物、NPC 导师、简化镜像切磋与个人蓝图创作。
- 成功指标（可验证）：
  1. 新玩家 3 分钟内完成：三选一 + 属性分配 + 进入第一次挂机。
  2. 离线 8 小时回来，离线报告正确结算并写入存档。
  3. 完成一次技能试炼：胜利三选一、失败蚀化、前 3 次必成功。
  4. 技能槽/保护位/净化/洗点可用且持久化；蚀化有醒目提示。
  5. 宠物收留 → 训练 → 学会 1 个功能型羁绊技。
  6. 个人受限蓝图：可编辑、超预算被拒、可保存草稿并在试炼中使用。
  7. 镜像切磋可打一场（战力镜像，禁用创作技能）。
  8. 主线第一幕完成并解锁第二区域。
- 非目标（明确不做）：
  - 真人师徒/好友/赠礼/好感度（P1）
  - 蓝图公开工坊、审核、分享码、评级（P1）
  - 赛季/分赛区/段位/限制赛（P1）
  - 实时 PVP、交易市场、跨服
  - 真实支付与服务端账号（MVP 用本地存档模拟）
  - 自由编程式技能

## 用户与场景

| 角色 | 目标 | 关键场景 |
|---|---|---|
| 新玩家 | 3 分钟看懂挂机与试炼 | 开局三选一、属性、首次挂机 |
| 放置玩家 | 每天上线收菜、推进度 | 离线报告、日蚀时刻、自动分解 |
| 构筑玩家 | 用试炼与个人蓝图做 Build | 技能试炼、技能背包、蓝图编辑器 |
| 独狼 | 不社交也能全通 PVE | 宠物线、NPC 导师、孤狼契约 |
| 竞技玩家 | 异步验证 Build（简化） | 战力镜像切磋 |

## P0 需求（MVP 必须）

| ID | 需求 | 页面/系统 | 验收 |
|---|---|---|---|
| P0-1 | 开局三选一永久技能，写入存档，不可替换 | onboarding | 选择后永久槽固定；重开仍保留 |
| P0-2 | 60 点属性分配，单项上限 24 | onboarding | 点数必须用完；超限禁用确认 |
| P0-3 | 安全/冒险挂机切换，收益与风险差异 | home | 两种模式产出/试炼概率不同 |
| P0-4 | 离线收益结算（上限 8 小时）+ 离线报告 | offline-report | 时长/资源/试炼结果正确；一键领取 |
| P0-5 | 技能试炼：胜利三选一、失败蚀化、前 3 次保护 | trial | 三选一可替换/放弃；蚀化持久化 |
| P0-6 | 技能槽：1 永久 + 1 非永久，10 级解锁第 2 个 | skills | 槽位数量按等级变化 |
| P0-7 | 保护位 1–2 个 + 金币洗点（10 级前免费） | skills | 保护中的技能失败不蚀化；洗点返还点数 |
| P0-8 | 蚀化净化：挂机/材料可完全免费修复；付费仅加速 | skills | 净化后恢复可用；加速不改变结果 |
| P0-9 | 每日日蚀时刻（蚀值/试炼/离线加成） | home | 时段内数值变化可观察 |
| P0-10 | 宠物收留 + 离线训练 + 1 个功能型羁绊技 | pet | 训练进度与技能学会可持久化 |
| P0-11 | NPC 导师：指导 + 绑定技能试用（替代真人社交） | social→home | 新手期可用，不依赖在线玩家 |
| P0-12 | 简化镜像切磋：战力镜像，无赛季/分赛区 | arena | 可设置防守、打一场、结算；创作技能不可上场 |
| P0-13 | 个人受限蓝图：模板/触发/词条/冷却/标签/预算/预览/三态草稿 | blueprint | 超预算禁止保存正式版；草稿可保存 |
| P0-14 | 主线第一幕：净化第一个蚀化节点，解锁第二区域 | story | 节点完成后区域 2 解锁 |
| P0-15 | 存档扩展与迁移（技能/宠物/竞技/主线/蓝图字段） | save | 旧档加载不丢数据；新字段有默认值 |
| P0-16 | 自动分解与背包上限设置 | bag | 低品质自动分解规则生效 |
| P0-17 | 新手保护：前 3 次试炼必成功或必出稀有 | trial | 前 3 次结果符合规则 |
| P0-18 | 挂机回流「防炸包」提示：有蚀化技能时主城顶部醒目警告并可一键跳转 | home | 离线/冒险失败后必出现；修复后消失 |
| P0-19 | 登录回流 3 分钟闭环：领离线 → 看报告 → 打一次试炼 → 关掉 | home/offline/trial | 操作路径不超过 3 个页面跳转 |

## 边界与异常

- 离线时长超过上限：按上限结算并提示。
- 属性点未用完/超上限：禁止确认。
- 槽满获得新技能：必须弹替换/放弃，不能自动丢弃。
- 保护位满：提示替换保护位。
- 蚀化状态下的技能不能被试用/出战。
- 净化免费但可加速：付费不得跳过「蚀化曾发生」的事实。
- 竞技场：创作技能不可上场；社交加成不生效；每日次数用尽提示。
- 试炼失败 3 次：触发保底提示。
- 挂机期间失败产生蚀化：回流首屏必须出现警告条（P0-18）。
- 存档损坏：沿用现有重置逻辑并提示。
