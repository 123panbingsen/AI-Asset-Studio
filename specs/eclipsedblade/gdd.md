# 游戏策划方案（GDD）

## 文档状态

- status: approved
- version: 0.4
- owner: lead
- last_updated: 2026-10-19

> 0.3 起整体定位从「动作养成 ARPG」调整为「宠物养成・社交放置 RPG」，并纳入技能创作子系统。
> 0.4 按评审意见收窄 MVP：真人社交与公开工坊后置 P1，个人蓝图进 P0，新增蚀化警告与商业化红线。批准后改为 approved。

## 一句话定位

- 项目 ID：`eclipsedblade`
- 游戏名称：EclipsedBlade（日蚀之刃）
- 品类：竖屏 **宠物养成・社交放置 RPG**（Social Pet Idle RPG）
- 核心体验：挂机是核心，RPG 是骨架，**玩家技能创作**是差异化；独狼靠宠物，社交靠师徒好友，长线靠赛季、蚀化之塔与转生。
- 世界观一句话：世界被不会结束的日蚀吞噬，玩家是最后一批持刃者，挂机探索蚀化区域、收集光与蚀碎片、培养同伴与宠物、重建传承，最终抵达日蚀源头选择结局。

## 目标用户与卖点

- 目标用户：碎片时间、喜欢放置成长与 Build 构筑、对社交强度不敏感的玩家（含独狼）。
- 核心卖点（3 条）：
  1. **挂机 + 试炼换技能**：低操作门槛，但每次试炼都有 Build 决策。
  2. **受限蓝图造技能**：模板 + 词条 + 硬预算，玩家能创作但不会被超模技能破坏生态。
  3. **双成长线**：师徒好友与宠物并行，社交是加速器不是门槛，独狼可全通 PVE。
- 竞品差异：不做实时 PVP、不做自由编程式技能；用「预算约束的创作 + 异步验证」替代。

## 核心循环

```text
回流 → 准备（流派/属性/技能/宠物/社交） → 挂机（安全/冒险/日蚀）
   → 试炼与战斗 → 成长（技能/蓝图/宠物/传承） → 长线验证（塔/Boss/赛季） → 转生
```

| 环节 | 玩家目标 | 主要界面 | 成功标准 |
|---|---|---|---|
| 回流 | 3 秒看到挂机收益与可领取奖励 | 主城、离线报告 | 离线报告一键结算 |
| 准备 | 调属性、换技能、带宠物、看好友 | 角色、技能、宠物、社交 | 主操作一键可达 |
| 挂机 | 离线/在线持续产出 | 挂机主界面 | 两种模式差异清晰 |
| 试炼 | 三选一换技能、验证 Build | 技能试炼 | 胜/败/保底反馈明确 |
| 成长 | 升级、升星、融合、造蓝图 | 技能背包、蓝图工坊 | 失败可修复，进度不倒退 |
| 长线 | 冲塔、打 Boss、赛季排名 | 蚀化之塔、竞技场 | 奖励为外观/材料，不卖强度 |

### genre-specific（品类必要，MVP 后）

真社交（师徒/好友/赠礼/好感度组合技）、蓝图公开工坊与审核、分享码与评级、词条碎片掉落、技能测试场、融合/变异、蚀化之塔（无限层）、世界 Boss/全服蚀潮、赛季排行榜与分赛区、限定赛、Boss 竞速、图鉴收藏、家园营地、限时活动。

### optional（可选）

实时 PVP、交易市场、跨服、UGC 编辑器进阶（脚本/条件分支）、宠物繁殖。

## 数值与养成（策划层）

### 属性

- 初始 60 点，六维：力量（物攻）、智商（技攻/蚀值效率）、速度（攻速/冷却）、体力（生命/回复）、生命（上限）、抗性（减伤/抗蚀）。
- 单项上限：单属性不超过总点数的 40%（24 点）。
- **爆发力 = f(力量, 速度, 智商)**，影响暴击、蚀值爆发与试炼胜率；不可直接加点。
- 洗点：前 10 级免费；之后金币/蚀能；洗点不重置永久技能。

### 技能

- 永久技能：1 个专属槽，不参与替换；每 10 级进化一次，材料解锁分支。
- 非永久槽：1 级 1 个，5 级 2 个，10 级 3 个，20 级 4 个，30 级 5 个，50 级 6 个。
- 技能品质：普通/稀有/史诗/传说；可升级、升星、合成；低品质可设自动分解。
- 槽满获得新技能：**替换或放弃**，不自动替换。
- 保护位：1–2 个；失败时优先不蚀化。
- 蚀化：暂时不可用，可挂机或材料净化；连续失败 3 次触发保底（下次必成功或必出史诗）。
- 新手保护：前 3 次试炼必成功或必出稀有；前 10 级失败不蚀化已有技能。

### 挂机

- 安全挂机：无试炼、收益低，适合长时间离线。
- 冒险挂机：有试炼、收益高，失败有代价。
- 日蚀时刻：每日固定时段，蚀值翻倍、试炼触发提高、离线收益增加。
- 离线收益上限 8–12 小时；上线弹离线报告。
- 背包上限；自动分解规则可配置。

### 蓝图（差异化）

- 组成：模板 + 触发条件 + 效果词条 + 消耗/冷却 + 标签 + 预算点。
- 硬预算：超预算不能保存为正式版；稀有词条成本更高。
- 三态：草稿 / 测试版 / 正式版；测试版不消耗正式材料。
- 测试场：木桩/镜像敌人，输出 DPS、蚀值、触发频率报告，可分享；有每日次数。
- 蓝图永久保留：蚀化只影响技能实例，蓝图不丢。
- 私人蓝图直接可用；公开需审核，进工坊按标签/预算/热度分类。
- 词条碎片：挂机、Boss、蚀化之塔掉落，解锁词条而非成品。
- 融合/变异：两个非永久技能融合，失败只耗材料、不删原技能；结果可转蓝图模板；有保底。
- 创作悬赏：每周主题（标签/预算/功能），按预算与效果评分给材料。
- PVP 隔离：自由创作技能默认不进普通 PVP，只进创作赛区（审核版、预算更严）。
- 商业化边界：只卖创作槽、仓库上限、测试次数、特效展示，不卖预算上限与强度。

### 组合技与羁绊技的词条方向（功能型，不给纯伤害）

好感度组合技与宠物羁绊技只投放**功能型**词条，防止平衡崩盘：

- 离线收益效率 +X%
- 蚀化修复/净化速度 +X%
- 材料/词条碎片掉落率 +X%
- 试炼触发率小幅提升
- 背包/离线时长上限小幅提升

不投放：纯伤害加成、PVP 胜率、预算上限。独狼若觉得效率不足，通过肝宠物亲密度补齐，而不是被迫社交。

## 社交与独狼

### NPC 导师（P0，替代真人拜师）

- 新手期由 NPC 导师给绑定技能试用与养成指引。
- 不依赖在线人数，独狼可完整体验。
- 真人师徒（师恩、出师、传承蓝图）放 P1，见下。

### 师徒（P1）

- 师傅给徒弟绑定技能试用权与指导；出师双方得奖。
- 师恩值换外观、称号、材料，不换强度；拜师位有上限，设备/账号绑定防小号。

### 好友（P1）

- 每日赠礼次数上限，只送低价值通用资源。
- 好感度靠互赠、组队挂机、组合技使用提升；稀有礼物靠活动/成就。

### 组合技（PVE 限定，P1）

- 好感度等级解锁，功能型为主：离线收益、试炼胜率、蚀化修复加速。
- 不进排行榜/PVP；付费只卖特效与好感度加速（有上限）。

### 宠物（独狼替代）

- 收留 → 离线训练 → 分支培养 → 学技能 → 亲密度羁绊技 → 进化。
- 宠物羁绊技约为好友组合技的 70%–80%，PVE 限定。
- 宠物技能 = 图鉴固定技能 + 受限宠物版蓝图（预算减半、标签限制），不直接复制玩家超模技能。
- NPC 导师替代拜师、流浪商人替代好友赠礼、器灵亲密度替代好感度。
- 孤狼契约：放弃真人社交，换取宠物训练加速与单人离线加成；可解除但社交进度清零。
- 原则：社交是加速器不是门槛，独狼能单人全通 PVE。

### 联网比赛（异步）

**P0（简化版）**：战力镜像切磋，无赛季/分赛区/段位，每日免费次数；失败不掉段位；创作技能不可上场。

**P1（完整版）**：

- 分赛区：社交赛区 / 独狼赛区；PVP 中社交加成不生效。
- PVP 独立技能池：官方技能 + 审核版蓝图；普通 PVP 禁用自由创作技能。
- 赛季 2–4 周：奖励外观、称号、材料，不卖强度。
- 限制赛/主题赛：限定品质、标签、宠物赛、低属性赛。
- Boss 竞速/伤害挑战：全服异步，展示蓝图配置便于传播。
- 防刷：每日次数、胜场奖励递减、设备绑定、回放举报。

## 主线（五幕）

| 幕 | 名称 | 解锁与内容 |
|---|---|---|
| 1 | 余烬之门 | 三选一、属性分配、安全挂机、第一次试炼、第一区域 |
| 2 | 蚀雾边境 | 冒险挂机、区域抗性、蚀化修复、拜师/宠物收留、第二区域 |
| 3 | 传承之城 | 蓝图创作、公开审核、好友赠礼、组合技、竞技场 |
| 4 | 全蚀之夜 | Boss 竞速、赛季比赛、独狼赛区、转生预告 |
| 5 | 日蚀源头 | 终局选择：光明 / 蚀影 / 平衡；隐藏结局与转生周目 |

主线任务形式：区域解锁、挂机目标、收集、社交目标、比赛目标、选择目标；奖励为区域权限、系统解锁、外观、材料，不直接给超模强度。

## 长线与商业化

### 长线

- 蚀化之塔：无限层，每 5 层 Boss，给永久蚀印；赛季重置保留部分。
- 世界 Boss/全服蚀潮：异步打 Boss，个人+全服进度，独狼可打低配版。
- 转生/多周目：保留永久技能进化、蓝图图鉴、宠物图鉴；多结局收集，真结局需集齐图鉴/宠物/蓝图/师徒出师。
- 每日/每周任务：挂机、试炼、赠礼、训练宠物、参加竞技。
- 限时活动：血月之夜、双蚀日、蚀潮来袭，给外观、宠物、称号。
- 图鉴/收藏：技能、宠物、Boss、结局图鉴，永久小加成。
- 家园/营地：布置宠物、展示蓝图、师徒信物，少量产出；卖皮肤与家具。

### 商业化原则（卖效率/外观/位置，不卖强度）

可以卖：离线收益上限、仓库/蓝图槽位、宠物携带/训练位、宠物返航加速与自动喂养、技能/宠物/组合技特效皮肤、洗点、试炼保护位、训练加速（小额有上限）、拜师位/好友位、师恩商店外观、赛季通行证、创作槽/测试次数/审核加速（不保证通过）。

不卖：直接强度、预算上限、审核通过权、必出传说词条、可交易宠物/技能、PVP 额外胜率。

### 商业化补充红线（0.3）

- **不卖「跳过试炼」**：试炼是核心特色，跳过等于拆掉玩法。
- **不卖「蓝图免审核」**：公开工坊必须审核，环境优先。
- **蚀化必须可免费修复**：挂机/材料可完全净化；付费只能加速净化，不能「无伤解除」制造焦虑变现。
- 可新增便利付费：宠物返航加速、自动喂养/清洁道具、离线收益上限延长。
- 所有付费项在 UI 必须标注「不增加战斗强度」。

## 风险约束

- 预算硬上限，PVP 独立池，公开蓝图审核 + 举报 + 回放。
- 连续超模蓝图下架/调预算，不封创作蓝图本体。
- 失败不删除进度（蚀化可修复）；保底机制防止长期负反馈。
- 离线收益有上限，防止无限挂机破坏经济。
- 社交不作为 PVE 门槛；付费不进入排行榜。

## 最小可玩版本（MVP，按参谋意见收窄）

1. 开局三选一永久技能 + 60 点属性分配
2. 安全/冒险挂机 + 离线 8 小时报告
3. 技能试炼：胜利三选一、失败蚀化可修复、前 3 次必成功
4. 1 永久槽 + 1 非永久槽，10 级解锁第 2 个
5. 技能保护位 + 金币洗点 + 蚀化净化（免费材料 / 付费加速）
6. 每日日蚀时刻
7. 宠物收留 + 训练 + 1 个功能型羁绊技（独狼线）
8. NPC 导师（替代真人社交）
9. 简化镜像切磋（战力镜像，无赛季/分赛区）
10. 个人受限蓝图：编辑器 + 预算校验 + 三态草稿（仅自己可用）
11. 第一幕主线：净化第一个蚀化节点，解锁第二区域
12. 存档迁移 + 自动分解 + 新手保护

**明确后置到 P1**：真人师徒/好友/赠礼/好感度、蓝图公开工坊与审核/分享码/评级、复杂赛季与分赛区、词条碎片掉落、测试场、融合/变异、蚀化之塔、世界 Boss。

## 待确认问题
